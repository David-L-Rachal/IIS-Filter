# Security Notice

This repository is a sanitized historical source snapshot. Production credentials, internal hostnames, deployment scripts, compiled binaries, build artifacts, archives, and legacy source-control metadata were removed or replaced with placeholders before publication.

The remaining code is preserved for historical and portfolio purposes and should not be deployed as a modern authentication or authorization system.

Do not commit real credentials to this repository. Use environment-specific configuration and an appropriate secret-management system for any future implementation.
